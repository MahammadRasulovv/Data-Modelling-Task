# Data Modelling Task

This repository contains the first homework for a Data Engineering Bootcamp, focused on data modelling and ERD design.

## Repository Overview

The project includes materials for the following modelling stages:

- **Conceptual model**
- **Logical model**
- **Physical model (Oracle SQL / PLSQL)**
- **ERD diagrams**

## Files in This Repository

- `Homework 1.1-1.2` — homework material for the initial modelling tasks
- `Homework 1.3.sql` — SQL script for the physical data model
- `ERD.drawio` — editable ERD diagram source file
- `ERD.png` — exported ERD image
- `Diagram Window.jpeg` — image preview of the diagram

## Purpose

The goal of this assignment is to demonstrate the process of translating a business/domain problem into:

1. a conceptual data model,
2. a logical data model,
3. a physical Oracle SQL implementation,
4. and a corresponding ERD.

## Tech Stack

- Oracle SQL / PLSQL
- Draw.io for ERD design
